# SOP 02 — Story schreiben

## Ziel

Eine kurze, natürliche Story bauen, die nur aus dem Bild entstehen konnte und nicht wie austauschbare Erotik-Copy klingt.

## Mögliche Bausteine

```text
sichtbarer Fakt + menschliche Mini-Situation + passende Reaktion/Frage
```

Das ist ein Denkmodell, kein festes Ausgabeformat. Eine Story kann ebenso nur aus einem starken Satz, nur aus einer offenen Stickerfrage oder aus einem plattformspezifischen Interaktionselement bestehen.

Beispielstruktur:

```text
i think i ordered the wrong size... 🤭
should i send it back... or is this exactly how you like it?
```

## Haupttext

Der Haupttext soll mindestens eines leisten:

- eine kleine Situation eröffnen
- einen visuellen Kontrast benennen
- eine sichtbare Handlung spielerisch deuten
- eine Fantasie ausdrücklich als Fantasie markieren

Gute Marker für Fantasie statt Tatsachenbehauptung:

- `imagine...`
- `should i...`
- `would you...`
- `i’d rather...`

## CTA / Fragen-Sticker

Der Sticker muss den Haupttext fortsetzen, nicht wiederholen.

Ein CTA ist optional. Vor jeder Ausgabe zuerst prüfen, ob ein einzelner Satz bereits genug Spannung und Reply-Potenzial besitzt.

### Gute CTA-Typen

1. **Konkrete nächste Handlung**
   - `should i pull my thong to the side? 🐱`

2. **Persönliche Präferenz**
   - `better with or without them?`

3. **Offene Fantasiefrage**
   - `what would you do with it? 😛`

4. **Bildbezogene Bestätigung**
   - `tell me... am i right?`

5. **Entscheidung aus einer Mini-Situation**
   - `should i send it back... or is this exactly how you like it?`

### Schlechte CTA-Typen

- `what do you think?`
- `do you like it?` ohne konkreten Bildbezug
- unklare Pronomen: `should i move it?`, wenn mehrere Objekte gemeint sein könnten
- eine Frage, deren Antwort bereits im Haupttext festgelegt wurde
- ein Sticker, der nur deshalb existiert, weil das Format sonst leer wirkt

## Zulässige Story-Formen

- nur normaler Text
- nur ein vollständiger Question-Sticker
- normaler Text plus Question-Sticker
- normaler Text plus Poll, Slider oder Reaktion, wenn die Plattform das Element tatsächlich unterstützt
- bewusst reduzierte Story ohne CTA, wenn Bild und One-Liner alleine tragen

Die konkrete Form wird nach Bildstärke und jüngster Story-Historie gewählt, nicht aus Gewohnheit.

## Intensität

Die gewünschte Intensität bestimmt die Direktheit, nicht die Bildtreue.

- **flirty:** Blick, Outfit, kleine Anspielung
- **nasty:** direkte Körper-/Kleidungsreferenz und konkrete Handlung
- **pervers:** explizitere Fantasie, aber weiterhin logisch aus Pose oder Outfit abgeleitet

Auch bei hoher Intensität niemals ein unsichtbares Detail als Tatsache ausgeben.

## Länge

- Haupttext: bevorzugt 8–18 Wörter
- Sticker: bevorzugt 4–12 Wörter
- maximal ein Hauptgedanke pro Element
- keine drei Alternativen anbieten, wenn eine beste Fassung gefragt ist
