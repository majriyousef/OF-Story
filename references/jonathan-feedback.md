# Jonathan-Feedback — verbindliche Referenz

Diese Datei fasst die im Projektverlauf verifizierten Feedbackmuster zusammen. Sie ist keine Sammlung frei erfundener Regeln.

## Kernprinzipien

1. Sichtbare Bilddetails zuerst.
2. Kurze, menschliche Situation statt generischer Erotik-Copy.
3. Natürliche Kleinschreibung im Englischen.
4. Einfache, direkt beantwortbare Interaktion.
5. Keine erfundenen Kleidungsstücke, Bewegungen oder Plattformfunktionen.
6. Ein starkes Bild kann nur normalen Text brauchen.
7. Wenn ausdrücklich `als Antwortsticker` gesagt wird, den Question-Sticker nutzen.
8. Wenn ausdrücklich `würde hier einfach nur schreiben` gesagt wird, keinen zusätzlichen Sticker erzwingen.
9. Content kann nach ungefähr drei bis vier Monaten erneut verwendet werden.

## Verifizierte Beispiele

### Leni — Werkbank

Nur normaler Text, kein zusätzlicher Sticker:

```text
all these tools, but which part of me would you work on first? 👀
```

Warum es funktioniert:

- Werkzeugwand und Werkbank werden direkt aufgegriffen.
- Das Wortspiel führt ohne zusätzlichen CTA zur Frage.
- Ein weiterer Sticker würde den Gedanken doppeln.

### Einzelne Hand verdeckt die Brust

Bevorzugte Richtung:

```text
this hand is doing a lot of work here 🤭
```

Warum es funktioniert:

- exakt sichtbares Detail
- kurz und natürlich
- keine falsche Behauptung darüber, wie viel tatsächlich bedeckt ist

### Lieblingspose

```text
just in case you're wondering, this is my favorite pose 😉
```

Passender Fragen-Sticker:

```text
what's yours? 🙈
```

Warum es funktioniert:

- Haupttext eröffnet eine persönliche Aussage.
- Sticker fragt nach einer eigenen Antwort und wiederholt nicht den Satz.

## Konsequenz für Reviews

Bei konkurrierenden Varianten gewinnt die Version, die:

1. weniger Annahmen benötigt,
2. stärker am Bild hängt,
3. natürlicher gesprochen klingt,
4. mit weniger Wörtern dieselbe Spannung erzeugt.
