# Private image inbox

Lege neue Storybilder in `assets/inbox/` ab. Der Inhalt dieses Ordners ist absichtlich von Git ausgeschlossen.

Empfohlene Dateinamen:

```text
YYYY-MM-DD_model_kurzbeschreibung.jpg
```

Beispiel:

```text
2026-10-04_jenny_pink-mirror.jpg
```

HEIC-Dateien vor der Analyse bei Bedarf lokal in JPG umwandeln. Das Original nicht überschreiben.
